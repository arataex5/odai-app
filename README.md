# お題ボックス

お題を出すタイプのボードゲームを **1つのアプリにまとめた** スマートフォン向け PWA です。
ゲームを切り替えると、表示方法とお題データがそのゲーム用に切り替わります。
LINQ アプリと同じ作りなので、お題の管理・ダーク／ライト切替・ルール説明・APK 化の手順はそのまま使えます。

- 収録ゲーム：**ほどよく／答えを合わせよう（ミステリーモードあり）／ワードっち／ぴったんこはんはん／カタカナーシ**
- ゲームごとに専用のデザイン（色・背景・ロゴの書体・お題カードの形）。ダーク／ライト両対応
- お題画面に **チェンジ**。チェンジ後だけ **一つ戻す／一つ進む** が出ます（ミステリーモード・ワードっちは対象外）
- 完全オフライン動作（Service Worker）。`file://` や APK でも埋め込みデータで動きます
- ダーク／ライトモード、画面の縦横切替（⟳）、セーフエリア対応
- ボードゲームは **あとから追加できます**（下の「ボードゲームの追加方法」）
- 現在のバージョン：**v1.3.3**

## 画面の流れ

```
ゲーム選択（ハブ）
 └ ゲームのタイトル ─ ルール説明 / お題リスト / 履歴 / 設定（→ お題の追加、削除）
     ├ ほどよく        ゲーム設定 → お題画面（親だけ見る・タイマー）→ 回答入力 → 正解判定（得点）→ 最終結果
     ├ 答えを合わせよう  通常：お題画面／フルゲーム：親を決める → お題選び（3択）→ せーの → 答えの入力・まとめ → 得点
     │                 ミステリー：役職確認 → せーの →（ズレたら）投票 → 結果
     │                 ミステリー・フルゲーム：役職確認 → [親 → お題選び → せーの → 入力] × ラウンド → 投票タイム → 役職公開 → 結果
     ├ ワードっち      ゲーム設定 → 基準選択（親だけ・2つから1つ）→ 暫定チャンピオン選択（3つから1つ）
     │                 → お題画面（挑戦ワードの記録・タイマー）→ 文字入力（決戦）→ 正解判定（優勝ワード）
     ├ ぴったんこはんはん お題画面（テーマ＋質問例3つ）
     └ カタカナーシ    お題画面（説明する人だけタップで表示）
```

| ゲーム | お題データ | タイマー | 判定 |
|---|---|---|---|
| ほどよく | 普通（403件・別解つき）／スペシャル（117件） | 設定で ON（初期 OFF・1分） | 普通＝自動判定、スペシャル＝親の答えを入れて自動 or 手動。○×はタップで変更可。得点：正解者 +1、親は正解者1人で +3／2人以上で +1（全員正解・全員不正解は 0）。「ゲーム終了」で順位表示 |
| 答えを合わせよう | 〇〇といえば？（529件・難易度1〜5の列あり） | ミステリーの投票タイム（初期3分） | フルゲームは答えを入力して自動でまとめ（似た答えは手動でまとめる） |
| ワードっち | 基準（194件）／ワード（422件） | 設定で OFF 可（初期 ON・3分） | 親が優勝ワードを選ぶ。勝利数を表示 |
| ぴったんこはんはん | テーマ＋質問例（64件） | なし | なし |
| カタカナーシ | カタカナのお題＋ジャンル（421件） | なし | なし |

### 遊び方（3モード）と得点

| ゲーム | ① お題だけ表示 | ② クイックスタート | ③ フルゲーム（〇点先取・初期値） |
|---|---|---|---|
| ほどよく | お題画面（＋タイマー） | 回答入力・正解判定あり、点数なし | 正解者 +1／親は正解者1人で +3・2人以上で +1（全員正解・0人は0）（10pt） |
| 答えを合わせよう | お題画面 | 読み上げ役が交代 | **協力＋得点**（5ラウンド）：全員一致＝移動なし、最多一致＝+難易度、ひとりだけ＝−難易度。全員一致がラウンド数の6割（切り捨て）に届けば全員の勝利、届かなければ最高得点の人の勝ち |
| 　ミステリーモード | 役職とお題表示（点数なし） | 役職を毎回配り直し、勝ったチームの全員 +1（5pt） | 役職は最初に1回。全員一致がラウンド数の4割（四捨五入）で仲間の勝ち。届かなくなったら投票 → 役職公開 → 勝敗 |
| ワードっち | 基準→チャンピオン→お題画面 | 決戦・優勝ワードまで、点数なし | 優勝ワードを出した人 +1（3pt） |
| ぴったんこはんはん | テーマ＋質問例 | 出題者が交代 | はんはん成功で出題者 +1（3pt）。参加者が偶数なら出題者も回答、奇数なら回答しない |
| カタカナーシ | お題画面 | 説明する人が交代 | 当たったら説明した人と当てた人 +1（5pt） |

クイック・フルゲームの順番は、全員が1回ずつ担当したら最初からくり返します。フルゲームは目標に届いて単独トップになったら勝利（同点トップは延長戦）。途中で「ゲーム終了」を押すと、その時点の順位で最終結果になります。

### チェンジ／一つ戻す／一つ進む

| ゲーム | 場所 |
|---|---|
| ほどよく | お題画面（出題者がお題を表示している間） |
| 答えを合わせよう（通常） | お題画面 |
| ぴったんこはんはん | お題画面 |
| カタカナーシ | お題画面（説明する人がお題を表示している間） |
| ミステリーモード・答えを合わせようのフルゲーム・ワードっち | なし（フルゲームは3つの候補から選ぶ方式） |

- チェンジは通常の抽選と同じ条件（使用済み除外・お気に入りのみ・除外リスト）で引きます。
- 「使用済み」になるのは **最後に表示していたお題だけ**。チェンジで飛ばしたお題は使用済みになりません。
- 「次のお題／次のラウンド」でチェンジの履歴はリセットされます。

### デザイン

| ゲーム | テーマ | ロゴ書体 |
|---|---|---|
| ほどよく | ほうじ茶色の温もり＋「ちょうどいい」温度ゲージ | Kiwi Maru |
| 答えを合わせよう | 「せーの」の波紋と吹き出し（ミステリーモードは月夜） | M PLUS Rounded 1c ／ Zen Antique |
| ワードっち | コミック風のタイトルマッチ（太い枠線・ドット・VS） | Dela Gothic One |
| ぴったんこはんはん | YES（青）と NO（赤）の二色割り | Mochiy Pop One |
| カタカナーシ | 藍と朱の原稿用紙＋「禁」の落款 | Yuji Syuku |

ロゴは `tools/make_logos.py` でフォントから SVG に変換して `js/core/logos.js` に入れてあります（フォント本体は同梱しないのでオフラインでも崩れません。フォントはすべて SIL Open Font License）。

- タイマーの時間は各ゲームの **設定** で分・秒を変更できます。0秒で音（Web Audio）＋バイブ＋「TIME UP!」表示。
- ワードっちの基準・ワードは、**選ばれたものだけ** が「使用済み」になります。
- プレイヤー名は全ゲーム共通で保存されます（番号をドラッグで順番入れ替え、シャッフルも可）。

## お題データの更新

1. `data/<ゲームID>/<セットID>.csv` を編集（Excel で開く場合は UTF-8 で保存）

   | ファイル | 列 |
   |---|---|
   | `data/hodoyoku/normal.csv` | No., お題, 別解（`/` 区切り） |
   | `data/hodoyoku/special.csv` | No., カテゴリー |
   | `data/awaseyou/odai.csv` | No., お題, 難易度（1〜5。1＝そろいやすい・5＝そろいにくい。空欄＝未設定） |
   | `data/wordcchi/kijun.csv` | No., 基準 |
   | `data/wordcchi/words.csv` | No., ワード |
   | `data/pittanko/themes.csv` | No., テーマ, 質問例1, 質問例2, 質問例3 |
   | `data/katakanashi/odai.csv` | No., お題（カタカナ）, ジャンル |

2. `python tools/embed_csv.py` を実行（オフライン用の埋め込みデータを同期）
3. `sw.js` と `js/core/store.js` の `APP_VERSION` を上げる
4. No. が入れ替わる差し替えのときは、そのゲームの `js/games/<ゲームID>.js` の `sets` にある `rev` を上げる
   （そのセットのお気に入り・除外・使用済み・履歴がリセットされ、別のお題に紐づくのを防ぎます）

アプリ内の「設定 → お題の追加、削除」からも追加・編集・削除できます（CSV 由来の「標準」お題は削除・編集不可）。

## ボードゲームの追加方法

1. `js/games/_template.js` をコピーして `js/games/<ゲームID>.js` を作る（ゲームIDは半角英小文字）
   - 名前・色・人数・お題セット・設定項目・ルール説明・画面をこの1ファイルに書きます
   - タイマー、プレイヤー設定、1人ずつ画面を見せる（役職確認）、回答入力、チェンジ／一つ戻す／一つ進む（`ctx.topicSlot` と `ctx.changeBar`）は共通部品を呼ぶだけで使えます
   - デザインは `css/themes.css` に `body[data-game="<ゲームID>"]` の色・背景を足す。書体付きロゴにしたいときは `tools/make_logos.py` の `LOGOS` に追加して実行
2. お題を `data/<ゲームID>/<セットID>.csv` に置く
3. `index.html` の「ボードゲーム」の所に `<script src="./js/games/<ゲームID>.js"></script>` を1行追加
4. `sw.js` の `ASSETS` に JS と CSV のパスを追加
5. `python tools/embed_csv.py` を実行
6. `APP_VERSION` を上げる

ゲーム選択画面には自動で並びます。Claude に頼む場合は「お題ボックスに〇〇を追加して」と、ルールとお題の形を伝えればOKです。

## 更新時の注意

- **`sw.js` と `js/core/store.js` の `APP_VERSION` を必ず両方上げる**こと（キャッシュが作り直されます）。
- HTML / JS / CSS はネットワーク優先、画像・CSV はキャッシュ優先です。

## GitHub での APK 化

LINQ と同じです。`.github/workflows/build-apk.yml` が Capacitor で Android アプリをビルドします。
はじめての場合は同梱の [`SETUP-GITHUB.md`](SETUP-GITHUB.md) を見てください。

1. GitHub でリポジトリ（例：`odai-app`）を作り、**このフォルダの中身をリポジトリ直下に** push
2. Settings → **Actions → General → Workflow permissions** を「Read and write permissions」に
3. Settings → **Pages → Source** を「**GitHub Actions**」に

push するたびに APK のビルドと Pages の更新が自動で走ります。

| 場所 | 内容 |
|---|---|
| Actions の Artifacts | `odai-box-apk-vX.Y.Z` |
| Releases | タグ `vX.Y.Z` に APK を添付 |
| `download/odai-box.apk` | 配布用。タイトル（ゲーム選択）画面のインストールボタンが参照 |

署名鍵の Secrets（`ANDROID_KEYSTORE_BASE64` ほか4つ）は LINQ と同じ名前・同じ手順です。未設定なら debug 署名でビルドされます。

| 項目 | 値 | 変更する場所 |
|---|---|---|
| アプリID | `com.odaibox.app` | `capacitor.config.json`（**公開後は変更しない**） |
| アプリ名 | `お題ボックス` | `capacitor.config.json` |
| versionName | `sw.js` の `APP_VERSION` | `sw.js` |

## 動作確認

Chromium（headless）で 390×844 / 375×667 / 横画面 844×390 を確認済み・コンソールエラーなし。

- ハブ → 各ゲームのタイトル・ルール説明・お題リスト（セット切替）・設定（タイマー分秒）・追加・履歴
- ほどよく：普通（自動判定・○×変更）／スペシャル（出題者の答え入力→自動判定）／タイマー0秒で TIME UP と音
- 答えを合わせよう：通常（次のお題・チェンジ）／協力フルゲーム（得点・まとめ・協力成功・得点勝負）／ミステリー（役職とお題表示・クイック・フルゲームの投票・決選投票・役職公開・全5種の勝敗）
- ワードっち：基準2択（親のみ）→ 3ワードから暫定チャンピオン → 挑戦の勝ち負け記録 → 基準ののぞき見 → 決戦入力 → 優勝ワード・勝利数
- ぴったんこはんはん：テーマと質問例3つ、次のテーマ
- カタカナーシ：タップで表示／隠す、お題がカタカナのみ、ジャンル表示
- チェンジ：チェンジ前は戻す／進むが非表示 → チェンジで別のお題 → 一つ戻す／一つ進むで行き来 → 端ではボタン無効 → 履歴には表示中のお題だけ残る（4ゲームで自動テスト）
- ミステリーモードの役職確認・ワードっちにはチェンジが出ないこと
- ダーク／ライト、縦横切替、`file://`（埋め込みデータで全6セット読込）
